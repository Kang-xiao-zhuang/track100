# Track100

> Every hour counts.

---

## Overview

Track100 是一个专注于长期目标追踪（Long-term Goal Tracking）的 Web App。

它帮助用户把一个庞大的目标拆解成可以看见的成长过程。

不同于传统 Todo List 或 Habit Tracker，Track100 更关注「累计投入」而不是「今日任务」。

例如：

- 阅读 100 本书
- 英语学习 100 小时
- 跑步 500 公里
- 写作 100 篇文章

用户每完成一次，就点亮一个格子。

最终形成属于自己的人生进度条。

---

## Product Philosophy

Track100 不是效率工具。

Track100 是成长工具。

它强调：

> Long-term Progress over Short-term Productivity.

关注长期积累，而不是每天完成多少任务。
